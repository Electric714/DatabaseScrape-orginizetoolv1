YOUR PARALEGAL RESEARCH WORKFLOW

From the old CSV to reviewed updates.

  1. Upload the existing bidder CSV.

    Use Upload existing CSV to load the firm’s current 30-column bidder database as the approved master starting point.

  2. Collect from the research sites.

    Set up each public research site and collect records. Scraped records are saved as source evidence and do not overwrite the master database.

  3. Compare collected data.

    Choose Compare collected data. Changed fields, new contractors, and ambiguous matches appear in the review queue with their source.

  4. Approve only the changes you want.

    Old values are red and newly found values are green. Choose Update, Add contractor, Keep old, or Dismiss. Approved changes become part of the master bidder database.

  5. Search and export the master.

    The main table and CSV, Excel, and JSON exports use the firm’s exact 30-column bidder layout. Technical collection history remains separate.

  6. Share a diagnostic report if something fails.

    Capture a snapshot, then Export report. This exports technical logs separately from bidder records.

Keep the launcher window open while using the app. Press Ctrl+C there when you’re finished. Saved records remain on your computer.
