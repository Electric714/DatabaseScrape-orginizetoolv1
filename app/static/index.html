WORKFLOW GUIDE

Approved truth and outside evidence stay separate

  1. Import the approved bidder CSV.

    The file establishes the master baseline. Missing rows are not silently treated as deletions.

  2. Run targeted research.

    Only approved master contractors are queried. Research creates evidence, not master edits.

  3. Inspect Evidence.

    Review the source URL, retrieval context, match basis, collection state, and extracted values.

  4. Run Comparison review.

    Current approved values and new research values are shown side by side. Ambiguous identities remain separate.

  5. Approve or dismiss each field change.

    Only explicit approval changes a master field. Research-created contractors cannot be approved into the master.

  6. Export the approved master.

    CSV, Excel, and JSON exports use approved master data, not unresolved evidence.
