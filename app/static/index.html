Workflow guide

Research workflow

  1. Import the bidder CSV.

    The file establishes the approved master database. Missing rows are not automatically treated as deletions.

  2. Run targeted research.

    Only contractors already in the master database are queried.

  3. Review Evidence.

    Inspect source URLs, retrieval context, match basis, collection state, and extracted values.

  4. Run Comparison review.

    Current approved values and new research values are shown side by side.

  5. Approve or dismiss each field change.

    Only approved changes update the master database.

  6. Export the master database.

    Exports use approved master data and exclude unresolved evidence.
